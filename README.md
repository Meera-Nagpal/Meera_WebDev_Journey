## 🌟 Featured Projects & Highlights

### 🏆 1. Smart India Hackathon (SIH) Platforms

#### 🛡️ `dp-edu` — Disaster Preparedness & Education Platform
A next-generation emergency drill and educational platform designed for institutional safety training and student crisis awareness.
- **Tech Stack:** React 19, Vite, Tailwind CSS v4, React Router v7, TanStack React Query, Heroicons.
- **Key Modules & Workflows:**
  - **Drill Simulator:** Interactive evacuation and safety procedure workflows.
  - **Emergency Alerts:** Real-time alert dispatch, notifications, and response instructions.
  - **Learning & Resources Portal:** Structured multimedia curriculum covering critical emergency protocols.
  - **Role-Based Portals:** Dedicated views for students, educators, and safety administrators.

#### 📊 `hierarch-hub` — Enterprise Hierarchy & Workflow Analytics Dashboard
A full-featured organizational management portal for visualizing complex reporting trees, task tracking, and team performance metrics.
- **Tech Stack:** React 18, Vite, TypeScript, Tailwind CSS, shadcn/ui, Radix UI Primitives, Framer Motion, Recharts, Lucide React.
- **Key Features:**
  - **Interactive Hierarchy Tree:** High-performance visual representation of organizational roles and nodes.
  - **Task Delegation Quick-Panel:** Fast-action task assignments with validation via Zod and React Hook Form.
  - **Live Analytics Cards:** Visual KPI metrics powered by Recharts (completion velocity, task status, capacity).
  - **Theme System:** Seamless dark/light theme switching with Next Themes and Radix dropdowns.

## 🚀 Getting Started

### Running the SIH Platforms

#### 1. `dp-edu` (Disaster Preparedness Education Platform)
```bash
cd SIH/dp-edu
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

#### 2. `hierarch-hub` (Hierarchy Analytics Dashboard)
```bash
cd SIH/hierarch-hub-main
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

#### 3. Static HTML / CSS / JS Projects
Simply open any `index.html` file in your preferred browser or serve with the VS Code **Live Server** extension.
